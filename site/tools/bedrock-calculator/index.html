Ways to cut it

    Why Bedrock bills surprise teams

    History is re-sent

    Message 10 of a chat sends the previous 9 questions and answers again. Input grows with every turn.

    Context is re-sent

    The system prompt, tool definitions and retrieved documents ride along on every call, often 10-50x the question itself.

    Agents multiply calls

    One question can become 3-10 model calls when an agent uses tools, each one with the full context.

    The extras are billed separately

    Guardrails per 1,000 characters per policy, an OpenSearch Serverless minimum around the clock, and logging per GB.

    Guardrails I set up so this never becomes a surprise

    • AWS Budgets and Cost Anomaly Detection alerts on the Bedrock spend
    • A hard daily and monthly cap with a kill switch, per user and per feature
    • max_tokens on every call, a history window, and prompt caching
    • Cost per feature with application inference profiles and tags
    • Guardrails scoped to user input, with PII redaction before logging
